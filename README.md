# Realstate – MERN Stack Application

A full-stack **MERN (MongoDB, Express, React, Node)** application for managing real-estate listings.  
Users can browse properties, view details, and (optionally) add/manage listings depending on role.

## 🚀 Tech Stack

**Frontend**
- React
- React Router
- Axios
- Tailwind / CSS (update if different)

**Backend**
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- JWT Authentication
